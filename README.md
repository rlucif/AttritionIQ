# AttritionIQ

Employee attrition risk engine for HR leaders. It predicts who is likely to leave, explains why, recommends retention actions, forecasts workforce loss and answers policy questions, all in one Streamlit app.

Data Science for Managers capstone. Covers all five sample project tracks.

| Track | Module | File | Algorithms |
|---|---|---|---|
| 1. Customer Intelligence | Workforce Segments | `src/segment.py` | K-Means, Hierarchical (Ward), DBSCAN, RFM-style scoring |
| 2. Decision Automation (core) | Risk Engine | `src/model.py`, `src/roi.py`, `src/audit.py` | Logistic Regression, Random Forest, XGBoost, MLP, SHAP, calibration, cost-optimal threshold |
| 3. Recommendation Systems | Retention Recommender | `src/recommend.py` | Content-based (SHAP drivers), collaborative filtering (Funk SVD), pay-rise elasticity |
| 4. Predictive Operations | Workforce Forecast | `src/forecast.py` | Ridge vs Lasso fair-pay model, ARIMA (optional Prophet), MLP |
| 5. Enterprise GenAI / NLP | HR Copilot | `src/rag.py` | Sentence embeddings, FAISS vector index, cosine vs Euclidean, LLM (RAG) |

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python -m src.data --download      # fetch the IBM dataset into data/raw/
# optional: save https://fred.stlouisfed.org/series/JTSQUR as data/external/JTSQUR.csv

python train.py --fast             # quick check (~1 min)
python train.py                    # full run: tuning, CV, figures, metrics
pytest -q                          # smoke tests
streamlit run app.py
```

`train.py` writes `models/attritioniq_bundle.joblib`, `reports/metrics.json` and charts in `reports/figures/`. The app only loads these, so it starts fast and every prediction on screen is computed live.

## Data sources

* **IBM HR Analytics Employee Attrition & Performance**: 1,470 employees, 35 columns. It is a synthetic dataset created by IBM data scientists, not real employee records. [Kaggle](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset); the download script uses IBM's copy on GitHub.
* **US JOLTS quits rate** (BLS, via FRED, series JTSQUR), monthly. Used only as a macro signal.
* **Replacement cost**: Gallup (2019) puts it at one-half to two times annual salary. [Article](https://www.gallup.com/workplace/247391/fixable-problem-costs-businesses-trillion.aspx)

## Things we state openly

* The IBM data is synthetic. Its currency and the time window of the Attrition label are not documented; we treat the label as "left within 12 months".
* The collaborative-filtering matrix is **simulated**: no real intervention history exists. Content-based recommendations use real model output.
* The HR handbook in `data/knowledge_base/` is a **template we wrote**; values in [brackets] are placeholders.
* Intervention cost and success rate are team assumptions. The app lets you change them and shows how the results move.
* SHAP values and the what-if tools show model sensitivity, not causal effects.
* Gender, age and marital status are excluded from the model by default; fairness is checked on the outputs.

## Optional: LLM and better embeddings

```bash
pip install sentence-transformers           # real embeddings instead of TF-IDF
pip install google-genai                    # or: pip install anthropic
export LLM_PROVIDER=gemini                  # or anthropic
export GEMINI_API_KEY=...                   # or ANTHROPIC_API_KEY=...
export LLM_MODEL=<current model name from the provider's docs>
```

Never commit API keys. Without a key the app shows a template brief, so the demo still works offline.
